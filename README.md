# Aniket Kiran — Cloud & DevOps Portfolio

A futuristic, high-performance developer portfolio built for **Aniket Kiran**, tailored specifically for **Cloud & DevOps Engineering, Platform Engineering, and Infrastructure Roles**.

Inspired by modern developer-terminal aesthetics with interactive 3D WebGL visuals, cosmic constellation particles, glassmorphism, and responsive design.

---

## 🌟 Key Highlights & Features

- **Terminal & Cosmic Aesthetic:** Deep obsidian dark mode (`#06080d`) with subtle ambient neon cyan glows, cybernetic corner brackets, and macOS-style terminal cards.
- **Interactive 3D WebGL Sphere (Three.js):** Real-time rotating cybernetic cloud mesh with glowing vertex nodes and orbiting latitude rings that respond to mouse parallax and click ripples.
- **Dynamic Holographic Profile Card Switcher:** Toggle smoothly between the interactive 3D mesh and a HUD-framed profile card featuring live ping status and scanline effects.
- **Interactive Constellation Canvas:** Background HTML5 canvas with drifting stars and dynamic mouse-connecting constellation lines.
- **Terminal Typewriter:** Cycles through key engineering titles (`Cloud & DevOps Engineer`, `AWS Certified Solutions Architect`, `Kubernetes & Infrastructure Specialist`, etc.).
- **Interactive Project Showcase:** Filterable project cards by category (`Cloud & DevOps`, `Full-Stack & APIs`, `AI & Deep Learning`) with architectural metric callouts, tech chips, and GitHub links.
- **Experience Timeline:** Glowing vertical timeline detailing internship contributions at **Pheme Software** (IBM Platinum Business Partner) and **Punjab National Bank**.
- **Categorized Toolbox:** Tech stacks grouped into Cloud Platforms, Containers & CI/CD, Software Engineering, and Databases & IaC.
- **AWS SAA-C03 Certification Banner:** Highlighted credential showcase for AWS Certified Solutions Architect Associate.
- **Interactive Contact & Copy Email:** Terminal-styled ping box with a 1-click email copy button featuring custom animated toast feedback.
- **Real-time Telemetry Status Bar:** Displays live scroll depth percentage (`00%` - `100%`), system status, and instant scroll-to-top button.
- **100% Responsive & Zero Build-Step:** Pure, lightning-fast HTML5, CSS3, and modern vanilla JavaScript.

## 🚀 Running Locally

Open [index.html](file:///d:/aniket-portfolio/index.html) directly in any browser, or run a local static server:

```bash
# Python
python -m http.server 4321

# or Node (npx)
npx serve .
```

Then visit `http://localhost:4321`.

## 🚢 Deploying to GitHub Pages / Vercel

### GitHub Pages:
1. Push all files to your GitHub repository (e.g., `Pavilioni5/portfolio` or `Pavilioni5.github.io`).
2. Navigate to **Settings → Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. GitHub Pages will deploy your site in seconds!

### Vercel:
1. Import your GitHub repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other**.
3. Root Directory: `./`.
4. Click **Deploy**.
